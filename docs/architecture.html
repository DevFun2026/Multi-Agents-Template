Core Architecture

Engineered for token & execution discipline

Key system invariants enforced across all supported agent runtimes.

Single-Level Delegation Authority

Orchestration is strictly bounded to a single tier (max_depth = 1). Subagents are forbidden from recursively spawning child workers (disallowedTools: Agent). The Main Controller retains sole ownership of architecture, conflict resolution, and final verification.

Exfiltration Hardening

Local codebase discovery is strictly decoupled from external web retrieval. No role combines shell commands with unconstrained network tools.

Concurrency Discipline

Read-only exploration runs in parallel. Workspace implementers run serially unless physical git worktree isolation is active.

Minimal Task Packets

Workers never inherit parent conversational history or full transcripts. The controller passes a compact packet: bounded objective, exact file paths, contract specifications, and verification criteria.

Security & Guardrails

Exfiltration & Network Defense

Command-position denial policies and automated validation gates.

Command-Position Rules

Denies curl and wget prefixes directly, in quotes, after path prefixes, after up to 2 VAR=val assignments, after env, and wrappers like sudo, xargs, and timeout.

Zero False Positives

Code inspections such as grep -r curl src/ or rg wget scripts/ are guaranteed not to be denied, allowing reviewers full static analysis access.

Engine Verification

Validated by scripts/test-gemini-policy.mjs against the real Gemini CLI 0.62.0 policy loader in both standard and YOLO execution modes.
